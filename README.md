# RPLVERSE – Digital Knowledge Universe (v0.1)
Game edukasi RPL berbahasa Indonesia. Tanpa build, tanpa backend, tanpa API key.

## Menjalankan
Modul ES butuh server lokal (jangan buka lewat file://):
    npx serve .        # atau: python3 -m http.server 8000
## GitHub Pages
Unggah seluruh isi folder ke repo, lalu Settings > Pages > Deploy from branch (root). Semua path relatif, jadi nama repo apa pun bekerja.
## Isi v0.1
Intro, menu, character creation, save IndexedDB (auto-save, ekspor/impor JSON, reset dengan konfirmasi), dashboard, dunia top-down Cyber Academy (gerak, tabrakan, NPC, koin), 3 materi + 10 soal berpenjelasan, battle Bug Monster 2 fase, quest, achievement, inventory + toko, audio sintetis, kontrol sentuh.
## Roadmap
Code City, Database Galaxy, Security Zone, Developer Dimension, 8 mini-game, Code Playground, skill tree, boss lain.
